## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/jaindhruv04/dhruv-portfolio.git
```

Navigate to the project:

```bash
cd dhruv-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Deployment

The portfolio is deployed using GitHub Pages.

```bash
npm run deploy
```
