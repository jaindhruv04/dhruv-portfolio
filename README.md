## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/jaindhruv04/dhruv-portfolio.git
cd dhruv-portfolio
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

### Deploy to GitHub Pages

```bash
npm run deploy
```

The `deploy` script builds the Vite application and publishes the `dist` directory using `gh-pages`.
